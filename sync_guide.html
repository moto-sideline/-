🧞 魔法のランプ Google Drive 自動同期ガイド

PC・スマホ間で原稿データを安全に自動同期するための手引書です。

LINEでこのページを開いている方へ

LINE内の画面（LINEブラウザ）のままだと、Googleアカウントとの同期ログインができないことがあります。
以下の方法で、標準ブラウザに切り替えてから設定を行ってください。
・iPhone: 画面右下の「・・・」をタップ → 「Safariで開く」
・Android: 画面右上の「・・・」をタップ → 「外部ブラウザ（Chrome）で開く」

PC・スマホ間で原稿を自動同期させる（詳細手順）

「PCでじっくり編集して、スマホで移動中にチャットしたい」という場合、Google Driveを仲介して原稿データを自動で同期させることができます。
※この設定には、Google Cloudでの簡単なシステム登録（クライアントIDの取得）が必要です。ご自身のGoogleアカウントがあれば、数分で完了します。

ステップ 1 Google Cloud プロジェクトの作成

  1. Google Cloud Console にアクセスします。
  2. 画面上部のプロジェクト選択メニューから「**新しいプロジェクト**」を選択して作成します。（名前は「Magic-Lamp-Sync」など何でも構いません）

ステップ 2 Google Drive API の有効化

  1. Cloud Consoleの上部検索バーに「**Google Drive API**」と入力します。
  2. 検索結果の「Google Drive API」をクリックし、青い「**有効にする**」ボタンを押します。

ステップ 3 OAuth 同意画面の設定

  1. 左メニューの「**APIとサービス**」＞「**OAuth 同意画面**」を開きます。
  2. ユーザータイプに「**外部**」を選択して「作成」を押します。
  3. 「アプリ名」「ユーザーサポートメール」「連絡先メールアドレス」を入力し、「保存して次へ」を最後まで進みます。
  4. **テストユーザーの設定**：テストユーザーに「**ご自身のGmailアドレス**」を追加します。（※これを忘れるとログイン時にエラーになります）

ステップ 4 OAuth クライアントID（認証キー）の発行

  1. 左メニューの「**認証情報**」を開きます。
  2. 画面上の「**＋認証情報を作成**」＞「**OAuth クライアント ID**」を選択します。
  3. アプリケーションの種類で「**ウェブ アプリケーション**」を選択します。
  4. **承認された JavaScript 生成元**に、以下のURLを登録します：
    https://moto-sideline.github.io
    (ローカルでテストする場合は http://localhost:8000 等も追加してください)
  5. **承認されたリダイレクト URI**に、以下のURLを登録します：
    https://moto-sideline.github.io/-/
    (※最後にスラッシュ / が必要です。ローカル用には http://localhost:8000/ 等)
  6. 「作成」を押すと、「**クライアント ID**」が表示されます。この長い文字列をコピーします。

ステップ 5 アプリケーションでのログイン

  1. 「魔法のランプ」アプリの左上（スマホは下部）にある **「Google Drive 同期」** アイコン（ ）をタップします。
  2. 「クライアントID」の欄に、Step 4でコピーした文字列を貼り付けます。
  3. 「**Googleでログインして同期開始**」を押し、画面の指示に従ってアクセス権を許可します。

※同期データはご自身のGoogle Drive of安全な隠しフォルダー（アプリデータフォルダー）にのみ保存され、第三者に公開されることはありません。

魔法のランプに戻る
