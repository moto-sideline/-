LINE内離脱 PWA（アプリ化） APIキー設定

LINEでこのページを開いている方へ

LINE内の画面（LINEブラウザ）のままだと、ホーム画面へ追加（アプリ化）ができません。 以下の方法で、標準ブラウザに切り替えてください。
・iPhone: 画面右下の「・・・」をタップ → 「Safariで開く」
・Android: 画面右上の「・・・」をタップ → 「外部ブラウザ（Chrome）で開く」

1. スマホのホーム画面に追加する（PWA）

ホーム画面にアプリとして追加すると、ブラウザのアドレスバーが消え、本物のスマホアプリとして全画面で快適にジーニーと会話できるようになります。

iPhone の場合（Safari）

  1. Safariでアプリを開き、画面下部にある 「共有ボタン」（四角から上矢印が飛び出しているマーク ）をタップします。
  2. メニューを下にスクロールし、「ホーム画面に追加」（プラスマーク ）をタップします。
  3. 右上の 「追加」 をタップすると、ホーム画面にランプのアイコンが作成されます。

Android の場合（Chrome）

  1. Chromeでアプリを開き、画面右上にある 「メニューボタン」（縦の3つの点 ）をタップします。
  2. メニューから 「アプリをインストール」 または 「ホーム画面に追加」 を選択します。
  3. 画面の指示に従って追加すると、ホーム画面にランプのアイコンが作成されます。
魔法のランプを開く

2. ジーニーを目覚めさせる「魔法の鍵」（API設定）

ジーニーを賢いAI編集者として動かすには、Googleの無料のAIキー（APIキー）を1つ設定します（登録・使用は完全無料ですのでご安心ください）。

ステップ 1 APIキーの新規作成

  1. 下のボタンから 「Google AI Studio」 へアクセスします。（※ログインを求められたらご自身のGoogleアカウントでログインしてください）
  2. 画面に表示される青い 「Create API Key」 ボタンを押します。
  3. プロジェクト選択画面が出たら、そのまま 「Create API Key in new project」 を選択します。
  4. 数秒後に長いコードが発行されるので、右側のコピーボタン（ ）を押してコピーします。
Google AI Studio でAPIキーを作成

ステップ 2 アプリへの貼り付けと保存

  1. ホーム画面から起動した「魔法のランプ」に戻ります。
  2. 画面の下部（または左メニュー）にある 「⚙️ 設定（歯車）」 を開きます。
  3. 「Gemini APIキー」の入力欄に、コピーしたキーを 貼り付け します。
  4. 「あなたの呼び名」を入力し、「保存して覚醒」 を押すとジーニーが目覚めます！
