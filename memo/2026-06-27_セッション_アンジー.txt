## 🐛 バグ詳細：LINE アイコンがグレーになる問題

### 症状
- スマホのボトムナビで LINE アイコンが LINE 公式グリーン（#00C300）ではなくグレーに見える

### コード確認結果
- `index.html` の SVG 自体には `fill="#00C300"` が正しく設定されている
- `style.css` では `nav-line-svg` にサイズと `filter: brightness(1.25)` のみ設定
- ボトムナビ用の CSS、またはダークモード・フィルターが SVG の `fill` を上書きしている可能性が高い

### 6/30 の修正案（アンジー or カーくんへ）
以下の CSS を確認・追加すること：

```css
/* スマホ用ボトムナビの LINE SVG に明示的に色を保護 */
#navLine .nav-line-svg rect {
    fill: #00C300 !important;
}
```

または、ボトムナビ用のスタイルで `filter` が SVG の色に干渉していないか確認する。
確認ファイル：`style.css` の L615〜L619 付近（スマホ用メディアクエリ内）
