【セッション概要】
- もとさんより v0.9.18（ステップ2：日常会話から裏でプロットを紡ぐ）の仕上げ依頼。
- 工房（アンジー）で着手済みの未コミット変更を pull 後確認し、背骨提案ロジックを「固定ターン数」から「3つの信号」方式へ最終調整。
- v0.9.18 として commit / push / GitHub Pages 反映まで実施。

【v0.9.18 実装内容（最終版）】
■ システムプロンプト刷新
  - 「3〜4往復で本提案」ルールを完全廃止。
  - 日常雑談最優先。書く気がないときは「話を聴く」が先（執筆支援アプリでも押し付けない）。
  - 裏でエピソード・想い・価値観をプロット素材として蓄積。

■ 背骨提案：3つの信号（固定ターン数は使わない）
  - 【信号A：意欲】「書きたい」「出版したい」「構成見せて」等 → 即執筆支援モード
  - 【信号B：素材】エピソード3本以上 + 想い・変化 + 届けたい相手が見える → 検討のみ
  - 【信号C：拒否】はぐらかした・雑談モード → そのセッション中は再提案しない
  - 提案文：「見る気があれば見てみて。なければこのまま話そう✨」（一度だけ・断られたら黙る）

■ UI
  - ステップ2プレースホルダー／サブタイトルを雑談トーンに統一。

■ バージョン
  - v0.9.18 / sw.js `magic-lamp-v38` / index.html `v=38`
  - v0.9.18 アップデート通知メッセージ追加

【もとさんとの設計議論メモ】
- 10往復・20往復の固定ターン数は「素材の厚み」の代理指標として不十分。
- 短い会話でも深い体験談なら早くてよい。長い雑談でも「うん」だけなら提案しない。
- 執筆意欲がないユーザーには背骨提案はうっとしく感じる → 信号Cで守る。
