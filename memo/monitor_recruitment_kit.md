## 📌 1. モニター募集の背景と目的

「ジーニー」は、ユーザーが何気なく語った言葉や想いを優しく受け止め、おしゃべりを通じて自然と本の構成案（プロット）や原稿の土台を紡ぎ出すAIです。今回のモニターテストでは、以下の検証・改善を目的とします。

* **対話のハードルの低さ検証**: 「本を書くぞ」と意気込まなくても、日常の雑談や考えの吐き出しから自然に対話をスタートできるか。
* **おもてなし（オンボーディング）の体験検証**: スマホへの追加（PWA）や、最初の呼び名設定からスムーズにジーニーとの「おしゃべり」に移行できるか。
* **フィードバックの収集**: ジーニーとの対話が心地よかったか、話しているうちに「これ本になるかも」というワクワク感が生まれたか。

## 📱 3. スマホへのインストール手順（モニター案内用）

「魔法のランプ（ジーニー）」は、スマートフォンのホーム画面に追加することで、まるで普通のスマホアプリのように全画面で快適に使える仕組み（PWA）を導入しています。

### 📱 0. 事前の準備

1. 運営より共有された「ジーニーのURL」をスマートフォンで開いてください。
2. アプリが開いたら、お使いのスマホ（iPhoneまたはAndroid）に合わせて以下のインストール操作を行ってください。

### 🍎 iPhone / iPad（Safari）

> **[！重要]**
> iPhoneでは、Google Chromeなどの他ブラウザからではホーム画面への追加が制限される場合があります。**必ず「Safari」ブラウザで開いて操作してください。**

1. Safariでアプリを開いた状態で、画面下部（iPadは右上）にある **「共有（アクション）ボタン」**（四角から上矢印が飛び出しているアイコン： 📤 ）をタップします。
2. メニューを下にスクロールし、**「ホーム画面に追加」**（プラスマークが付いた四角いアイコン： ➕ ）をタップします。
3. アプリ名が「魔法のランプ」と表示されます。右上の **「追加」** をタップします。
4. ホーム画面に **ランプのアイコン** が作成されます！

*※LINEや他のアプリの中から開いた場合は、右下の羅針盤マーク等を押して「Safariで開く」を選んでから操作してください。*

### 🤖 Android（Google Chrome）

> **[！重要]**
> Android端末では、標準ブラウザとして **「Google Chrome」** を使用して操作を行ってください。

1. Chromeでアプリを開いた状態で、画面右上にある **「メニューボタン」**（縦に点3つ： ⋮ ）をタップします。
2. メニューから **「アプリをインストール」** または **「ホーム画面に追加」** をタップします。
3. 確認画面が表示されたら、**「インストール」** または **「追加」** をタップします。
4. ホーム画面に **ランプのアイコン** が作成されます！

### 🚀 インストール後の起動と設定

1. **アプリとして起動する**
   ホーム画面のアイコンをタップして起動してください。ブラウザのアドレスバーや戻るボタンが消え、スマホ画面全体でアプリとしてすっきり起動します。
2. **AIを覚醒させる（初期設定）**
   * 画面の **「⚙️ 設定（歯車マーク）」** をタップします。
   * Googleアカウントを使って「Google AI Studio」（無料）からAPIキーを取得し、設定画面に貼り付けて **「保存して覚醒」** を押してください。
   * これでジーニーとチャットで会話を始められます！

## 🧞 4. ジーニーとのおしゃべり 3ステップ

まずは難しく考えず、ジーニーを「話し相手」として使ってみてください。

```mermaid
graph TD
    A[1. ジーニーとおしゃべり] -->|日常のこと・想い・アイデアを語る| B[2. 原稿キャンバスを覗く]
    B -->|気づけば目次プロットに整理されている!| C[3. 結晶化して保存]
    C -->|いつの間にか本の下書きが完成| D((本棚に保管完了!))
```

1. **まずは自由におしゃべりする**
   * チャット画面でジーニーの質問（お名前や、最近気になっていること）に答えていきます。
   * 「本を書く」と気負う必要はありません。「今日こんなことがあってね」「昔こんな仕事をしていてね」と、友だちとおしゃべりするように話しかけてください。
2. **整理された「キャンバス」を覗いてみる**
   * おしゃべりしていると、メニューの「原稿キャンバス（羽ペンのマーク）」に、ジーニーが会話の内容を整理した「本の目次（プロット）」を自動で組み立てていきます。
   * 「自分の話がこんなふうに整理されるんだ！」という変化を眺めるだけでも楽しめます。
3. **気に入ったら保存する**
   * 対話が弾んで「これ、いつか本にしてみたいな」と思ったら、「原稿を研ぎ出し・出力（結晶化）」ボタンを押します。
   * 整理されたテキストがファイルとして保存され、アプリ内の「本棚（本のマーク）」に保管されます。

💡 **ワンポイントアドバイス**
「何を書けばいいかわからない…」という時も、そのまま「書くことが思いつかない」とジーニーに話してみてください。ジーニーがあなたの興味を優しく引き出す質問をしてくれます。

## 📝 5. フィードバックをもらう方法

### 📋 フィードバック質問項目案（「おしゃべり体験」フォーカス版）

#### 1. 導入（API設定・インストール）について
* **質問**: アプリを使える状態にするまで（APIの設定やスマホ画面への追加）は難しくなかったですか？
* **選択肢**: とても簡単だった / 少し難しかったができた / 難しくて誰かの助けが必要だった

#### 2. 対話の「話しやすさ」について
* **質問**: ジーニーとの対話は話しやすかったですか？（話し方、返事のペースなど）
* **選択肢**: 友だちのように話しやすかった / 優しいと感じた / 少し冷たい・機械的に感じた / 返事が遅すぎる・早すぎる / その他

#### 3. 「いつの間にか整理される」体験について
* **質問**: ジーニーとおしゃべりしているだけで、話が「本の目次（プロット）」として整理されていくのを見てどう思いましたか？
* **選択肢**: 自分の体験が整理されて感動した・ワクワクした / 新鮮で面白かった / あまりよく分からなかった・ピンとこなかった
