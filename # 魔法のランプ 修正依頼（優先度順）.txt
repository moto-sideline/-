# 魔法のランプ 修正依頼（優先度順）

対象: index.html / script.js / version.js / sw.js
目的: 下記6点の不具合を修正する。

## 進め方のルール（必ず守ること）
- 1項目ずつ修正し、項目ごとに「変更した行の前後（差分）」を見せること。
- 指定した箇所以外のコードは変更しないこと。
- 「直した」と報告する前に、各項目の【確認テスト】を実際に実行し、その出力結果を貼ること。実行していないテストを「通った」と書かないこと。
- 分からない点や、確認できなかった点は、推測で埋めずに正直に書くこと。

## 1. 挨拶のあとの文章が消えるバグ（最優先）
場所: script.js の cleanLeadingExclamations 内、ステップ2（isReplyAfterGreeting の分岐）
問題: 「おはよう！今日も頑張ろうね。」が「。」になるなど、挨拶の直後の文が丸ごと消える。
修正: ステップ2の正規表現を、挨拶の言葉だけを消す次のものに差し替える。
/^(?:お?久しぶり(?:だね|です)?|おかえり(?:なさい)?|おはよう(?:ございます)?|こんにちは|こんばんは|お疲れ様(?:です)?|おつかれさま(?:です)?)[！!♪〜~、,，\s]*/i
（挨拶の直後の名前やその他の語を消す部分は削除する）
【確認テスト】Node.js で次を実行して結果を貼る。
- 「おつかれさま！それは大変だったね。」→「それは大変だったね。」
- 「おはよう！今日も頑張ろうね。」→「今日も頑張ろうね。」
- 「それは大変だったね。」→ 変化なし

## 2. 目次（プロット）の自動検出
場所: script.js の handleSend 内、plotLines を作る filter（「第.章|プロローグ|エピローグ|[\d]+\.」の正規表現）
問題: 「**第1章：旅立ち**」「### 第1章」「第10章」を見逃す。また、普通の「1. 2. 3.」の箇条書きを目次と誤認して、プロットを上書きする。
修正: 判定を次の正規表現に変更する（数字だけの箇条書きは対象外にする）。
/^[\s*#>\-・]*(?:\*\*)?(第[0-9０-９一二三四五六七八九十]+章|プロローグ|エピローグ)/
保存するタイトルからは、先頭の記号（* # など）と、末尾の ** も取り除くこと。
【確認テスト】次の入力で、検出される/されないを一覧で貼る。
- 検出される: 「第1章：旅立ち」「**第1章：旅立ち**」「### 第1章：旅立ち」「* **第2章：出会い**」「第10章：終わり」「プロローグ：はじまり」
- 検出されない: 「1. 朝は早起きしよう」

## 3. Geminiモデルの扱い
場所: script.js の getGeminiModel、起動時の初期化部分、DEFAULT_GEMINI_MODEL、PREFERRED_MODEL_ORDER。index.html の apiModelSelect。
問題: gemini-2.5 / gemini-3. で始まるモデルを、強制的に gemini-2.0-flash に戻している。2.0 Flash は2026年6月1日にAPI提供が終了したとの情報があり、毎回、失敗してから別モデルに切り替わっている可能性が高い。
修正:
- 「2.5 / 3. で始まるモデルを 2.0 に戻す」処理を削除する。
- 初期モデルは、Google公式のモデル一覧（ListModels API か公式ドキュメント）で実在を確認できる Flash 系の現行モデルにする（候補: gemini-3.5-flash）。確認できなければ、その旨を報告すること。
- PREFERRED_MODEL_ORDER と apiModelSelect の選択肢も、現行のモデルに更新する。終了済みのモデルは外す。
- 自動検出で選んだモデルが、次のリクエストで書き換えられないこと。
【確認テスト】モデル名が localStorage に保存されたあと、getGeminiModel() がそのモデルをそのまま返すことを確認して結果を貼る。

## 4. 固定の「出版のヒント」文を削除
場所: script.js の updatePreview 内（「✨ 出版のヒント：このエピソードは、第1章の「共感」を呼ぶパートで非常に強力な武器になります。」）
問題: 内容と無関係な固定文が、AIの分析のように表示される。
修正: この固定文のブロックを削除する。

## 5. バージョン表記と HTML の崩れ
- version.js: APP_VERSION を '1.0.0'、APP_STAGE を 'Stable' に分ける（script.js が v を前に付けるため、現状は「vv1.0.0 Stable Beta」と表示される）。
- index.html: <main class="line-chat"> の終わり付近にある、余分な </div> を1つ削除する。
【確認テスト】script.js の表示用文字列の組み立てを Node.js で再現し、「魔法のランプ v1.0.0 Stable」と出ることを確認して貼る。

## 6. 安全面の修正
a) バックアップにAPIキーを含めない
 - exportBackup から geminiApiKey を外す。importBackup でも、ファイルに geminiApiKey があっても読み込まない。
b) HTMLエスケープ
 - escapeHtml(str) を作り、& < > " ' を変換する。
 - renderMessage の user / genie のテキスト、資料室の一覧の資料名（m.name）など、ユーザーや外部のデータを innerHTML に入れている箇所に適用する。改行の <br> 変換はエスケープのあとに行う。
 - 画像の src は、data:image/ で始まる場合だけ許可する。
 - index.html のエラーバナーは、メッセージ部分を textContent で入れる。
【確認テスト】「<img src=x onerror=alert(1)>」を入力して、画面上でただの文字として表示されることを確認する。

## 7. 最後に（キャッシュ更新）
sw.js が cache-first のため、修正が配信先に届くよう、CACHE_NAME を 'magic-lamp-v109' に、index.html の ?v=108 をすべて ?v=109 にそろえて更新する。
